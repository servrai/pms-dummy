What this polygon is

pms-dummy is a disposable cloud-PMS implementing servr.ai's PMS webhook contract: it receives servr's signed action deliveries (POST /actions), answers reservation reads (GET /pms/reservations/{booking_ref}), and sends signed events back (reservation.sync, reservation.record, reservation.deleted, action.confirm).

To wire it into dev: Hotel Settings → Integrations → PMS, mode Webhook, base URL of this host, the two paths and the signing secret from Webhook settings.

The same integration also ships an RPA transport for on-premise PMSes — an adapter on a hotel PC polls five endpoints instead of webhooks. pms-dummy mirrors the webhook lane only; use it to test signatures, deliveries, retries and both event directions.
